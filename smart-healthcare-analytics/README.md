# 🩺 Smart Healthcare Analytics System

The **Smart Healthcare Analytics System** is a web platform designed to analyze patient health data and predict the risk of chronic diseases such as diabetes, heart disease, stroke etc. The system integrates machine learning, data analytics, explainable AI, real-time communication, and an AI chatbot to support intelligent healthcare decision-making.

---

## 📌 Project Overview

This system transforms raw patient data into meaningful medical insights using:
- Machine Learning for disease risk prediction  
- Data analytics and visualization  
- Explainable AI
- Real-time doctor–patient chat  
- Integrated AI medical chatbot  
- Streamlit-based interactive interface  
- Flask-powered backend API  

The project is actively under development with continuous feature enhancements.

## ⚙️ How to Run the Project

1. **Clone the repository**
```bash
git clone https://github.com/ArayikGevorgyan/Proj_S5.git
cd smart-healthcare-analytics
```

2. **Install Required Dependencies**
```bash
pip install -r requirements.txt
```
3. **Train the Machine Learning Model**
```bash
python3 src/train_model.py
```
5. **Start the Streamlit Application**
```bash
streamlit run app.py
```
